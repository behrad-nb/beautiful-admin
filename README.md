## English

Beautiful Admin gives your WordPress dashboard a modern, clean, and elegant appearance.

It improves the visual style of the WordPress admin area, including:

- Colors
- Cards
- Buttons
- Tables
- Form fields
- Menus

### Our Philosophy

Beautiful Admin changes only the appearance of your dashboard.

It does not change the original WordPress layout or move any menus, buttons, or interface elements. Everything stays exactly where WordPress originally placed it.

A beautiful dashboard, with the same familiar experience.

---

## فارسی

پنل زیبا (Beautiful Admin) افزونه‌ای برای مدرن‌تر و زیباتر کردن محیط مدیریت وردپرس است.

این افزونه ظاهر بخش‌های مختلف پیشخوان وردپرس را بهبود می‌دهد، از جمله:

- رنگ‌بندی محیط مدیریت
- کارت‌ها و پنل‌ها
- دکمه‌ها
- جداول
- فیلدهای ورودی
- منوها

### فلسفه طراحی

پنل زیبا فقط ظاهر محیط مدیریت وردپرس را تغییر می‌دهد.

هیچ تغییری در ساختار و چیدمان اصلی وردپرس ایجاد نمی‌کند و منوها، دکمه‌ها و سایر عناصر رابط کاربری دقیقاً در جای اصلی خود باقی می‌مانند.

پیشخوانی زیباتر، با همان تجربه آشنای همیشگی.
